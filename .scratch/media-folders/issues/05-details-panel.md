# 05: Details panel

**What to build:** An editor sees read-only details of the selected Media or folder in a panel on the right.

**Blocked by:** 03 — Folder-scoped grid and Recent view

**Status:** ready-for-agent

- [ ] Selecting a Media card shows its details: name, type, size, dimensions, MIME type, checksum, storage driver, usage count, public URL, created and updated dates.
- [ ] Selecting a folder card shows its details: name, item count, total size, created and updated dates.
- [ ] The panel shows an empty or placeholder state when nothing is selected.
- [ ] The panel updates immediately when the selection changes.
- [ ] Component tests verify the rendered details for a Media and a folder.
